Welcome to Exploring Github

This is a simple HTML page to demonstrate the structure of a basic web.

git add .

This command stages all the changes in the current directory for the next commit. It adds new files, modified files, and deleted files to the staging area.

git commit -m "Your meaningful commit message"

This command creates a new commit with the changes that have been staged. The -m flag allows you to include a meaningful message describing the changes made in that commit.

git push origin main

This command uploads your local commits to the remote repository on the branch named "main". It syncs your local changes with the remote repository so that others can see them.
